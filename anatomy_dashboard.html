1. Sistem Integumen / Kulit

Integumentary System
Rajah 1.1 — Struktur Lapisan Kulit Manusia

Definisi & Fungsi

Sistem integumen merupakan organ terbesar badan manusia (~4–5 kg, permukaan 1.5–2 m²). Meliputi kulit, rambut, kuku dan kelenjar berkaitan.

Fungsi Utama

  • Perlindungan fizik & kimia
  • Pengaturan suhu badan
  • Sensasi (sentuhan, sakit, haba)
  • Sintesis Vitamin D
  • Ekskresi melalui peluh

Lapisan Kulit

  • Epidermis: Corneum→Basale (sel, melanosit)
  • Dermis: kolagen, elastin, saluran darah
  • Hypodermis: tisu lemak (adiposit), penebat haba
📌 Melanosit di stratum basale menghasilkan melanin yang melindungi DNA daripada sinaran UV.

3. Sistem Otot

Muscular System
Rajah 3.1 — Tiga Jenis Otot & Struktur Sarkomer

Tiga Jenis Otot

JenisKawalanLokasiHistologi
RangkaSukarelaMelekat pada tulangBergaris, multinukleus
JantungTidak sukarelaDinding jantungBergaris, disk interkalated
LicinTidak sukarelaOrgan dalaman, sal. darahTidak bergaris, 1 nukleus

Mekanisme Kontraksi (Teori Gelongsor Filamen)

  1. Impuls saraf → persimpangan neuromuskular (NMJ)
  2. ACh dibebaskan → depolarisasi sarcolemma
  3. Ca²⁺ dibebaskan dari retikulum sarkoplasma
  4. Ca²⁺ + troponin → dedah tapak aktif aktin
  5. Kepala myosin terikat aktin → power stroke
  6. ATP bebaskan kepala myosin → kitaran berulang
📌 Kontraksi memerlukan ATP & Ca²⁺. Rigor mortis berlaku apabila ATP habis selepas kematian.

7. Sistem Limfatik

Lymphatic System

Fungsi & Organ Limfoid

Fungsi

  • Pengaliran cecair interstisial semula
  • Pengangkutan lemak (lakteal)
  • Imuniti — tapisan patogen

Organ Limfoid

  • Nod limfa (~600)
  • Limpa
  • Timus
  • Tonsil
  • Sumsum tulang

Imuniti

Bawaan (Non-Spesifik)

  • Kulit & membran mukus
  • Keradangan, demam, neutrofil
  • Sel NK, komplemen, interferon

Adaptif (Spesifik)

  • Sel-B → antibodi (humoral)
  • Sel-T sitotoksik (sel)
  • Sel memori (asas vaksin)
📌 ~600 nod limfa dalam badan. Nod membesar semasa jangkitan kerana sel imun berganda.

8. Sistem Pernafasan

Respiratory System

Laluan Udara

Hidung/Mulut → Farinks → Larinks → Trakea → Bronkus Primer → Bronkus Sekunder → Bronkiol → Bronkiol Terminal → Alveolus

Inspirasi

  • Diafragma mengecut (turun)
  • Otot interkostal luar mengecut
  • Isipadu dada meningkat → tekanan turun → udara masuk

Ekspirasi

  • Diafragma relaks (naik)
  • Isipadu dada berkurang → tekanan naik → udara keluar

Kapasiti Paru-paru

ParameterNilai (dewasa)
Isipadu Tidal (TV)~500 mL
Kapasiti Vital (VC)~4,600 mL
Kapasiti Jumlah (TLC)~6,000 mL
Kadar normal12–20 nafas/min
📌 Surfaktan melindungi alveolus daripada kolaps. Kekurangannya pada bayi pramatang menyebabkan NRDS.

9. Sistem Penghadaman

Proses Penghadaman

  1. Ingesti: pengambilan makanan
  2. Mekanikal: kunyahan, peristalsis, segmentasi
  3. Kimia: enzim memecah molekul besar
  4. Penyerapan: nutrien → darah/limfa
  5. Defekasi: buang sisa

10. Sistem Urinari

Urinary System

Komponen

OrganFungsi
Ginjal (2)Tapisan darah, pembentukan urin, keseimbangan elektrolit & pH
Ureter (2)Saluran ginjal → pundi kencing
Pundi KencingSimpan urin (~500 mL)
UretraSaluran membuang urin

Pembentukan Urin dalam Nefron

  1. Penapisan Glomerular: cecair tolak dari kapilari ke kapsul Bowman
  2. Reabsorpsi: glukosa, asid amino, Na⁺, air diserap semula
  3. Penyekresian Tubular: H⁺, K⁺, ubat, toksin → lumen tubul
  4. Pengumpulan: urin pekat → pelvis renal → ureter
📌 Setiap ginjal: ~1 juta nefron. Tapisan: ~180 L/hari, urin dikeluarkan: ~1.5 L/hari.
